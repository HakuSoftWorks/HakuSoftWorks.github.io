About Haku Soft Works

Haku Soft Worksは、日本のクラシックコンピュータを対象とする独立した個人ソフトウェア開発プロジェクトです。

“Software for Classic Japanese Computers” をテーマに、ソフトウェア、技術資料、実機での動作記録を公開していきます。

Focus

BASIC MASTER series / Motorola 6800 / Retro software development / Ports / Reimplementations / Documentation

古いハードウェアの制約を理解し、その制約の中で工夫することもHaku Soft Worksの開発テーマのひとつです。
