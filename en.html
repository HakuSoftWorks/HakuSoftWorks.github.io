Software for Classic Japanese Computers

Haku Soft Works develops, ports, tests, and documents software for classic Japanese computers, with a particular focus on the BASIC MASTER series and Motorola 6800-compatible systems. We work with both original hardware and emulators to keep these machines alive as platforms for software that still runs today.

Projects

Released software and projects currently being developed by Haku Soft Works.

Released v1.0

REVERSI

A computer-opponent Reversi game for the BASIC MASTER LEVEL2II. Built for an approximately 750 kHz CPU and 16 KB of RAM, it features three COM levels, legal-move indicators, Negamax search, alpha-beta pruning, positional evaluation, endgame search, and visible thinking-time feedback. Version 1.0 is available on GitHub, with a 10-part development series on note.

Released v1.0

CARD GAMES Vol.1

A four-game card collection for the BASIC MASTER LEVEL2II: SEVENS, OLD MAID, 5-CARD DRAW POKER, and DOUBT. Shared card, deck, and hand routines allow all four games to fit into a single program for the 16 KB RAM environment. Version 1.0 is available on GitHub, with development notes and a real-hardware video also published.

About Haku Soft Works

Haku Soft Works is an independent personal software-development project focused on classic Japanese computers.

Under the theme “Software for Classic Japanese Computers,” we publish software, technical documentation, and records of programs running on original hardware.

Focus

BASIC MASTER series / Motorola 6800 / Retro software development / Ports / Reimplementations / Documentation

Understanding the limitations of old hardware—and finding creative ways to work within them—is a central part of the project.
